LOCAL TOOLBOX / STATIC PUBLISHING

一个命令入口，
把工作发布出去。

gd 支持 Windows 和 Linux，管理本地脚本、阿里云 OSS 文件与静态站点。站点地址保存在本机配置；同一个发布命令可把文件送到 ChatGPT Site 或自有服务器。

Windows / Linux · gd
# 查看已配置的站点
❯ gd site list

# 发布页面并回读校验
❯ gd site publish ./dist

# 注册本地脚本
❯ gd add hello ./examples/hello.py
GD / 02站点读写分离 · 写入密钥留在本机 · 文件回读核对 SHA-256
TOOLBOX

三个清楚的入口

常用操作留在命令行；配置、凭证和发布目标分别管理。

MODULE / 01

脚本

注册 Python、PowerShell 或 Bash 脚本，从任意目录以名称运行。注册信息保存在用户目录。

gd add · gd list · gd run
MODULE / 02

OSS

上传、下载和检索对象。Windows 上可选 WLAN 直连，避免本机代理路径影响连接。

gd oss put · gd oss get · gd oss ls
MODULE / 03

站点

本地配置站点地址，用带密钥的 HTTP 接口发布静态文件，并从公开页面核对结果。

gd site add · gd site login · gd site publish
PUBLISH FLOW

从本地文件到浏览器

发布后的页面由站点直接返回正确的 HTML 类型，浏览器可直接打开。

01 / CONFIGURE

配置目标

保存 ChatGPT Site 或自有服务器的网址。配置文件默认位于 ~/.gd/sites.json。

02 / UPLOAD

上传文件

命令递归发送静态文件。写入请求需要密钥；隐藏文件、凭证文件和符号链接不会发布。

03 / VERIFY

回读确认

逐个检查公开地址的 SHA-256 响应头。上传接口成功但页面未可用时，命令会报错。

TWO TARGETS

同一命令，两种托管

浏览地址和写入密钥只在本机配置；站点页面不包含写入密钥。

ChatGPT Site

先配置公开站点地址，再从终端安全输入该站点的写入密钥。

gd site add chatgpt --provider chatgpt --url https://your-site.chatgpt.site
gd site login chatgpt
gd site publish ./dist --site chatgpt

自有服务器

gd 可运行静态文件服务；公网使用时由你自己的 HTTPS 反向代理连接本机监听端口。

gd site add myserver --provider self --url https://example.com --root ./public
gd site login myserver
gd site serve --site myserver --port 8765

站点公开地址用于浏览；写入操作只接受带密钥的请求。ChatGPT Site 的站点代码和存储先完成一次部署，后续页面更新直接通过 gd site publish。
