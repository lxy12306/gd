GD / GUIDE

gd 使用说明

一个命令入口，管理本地脚本、阿里云 OSS 和静态站点。支持 Windows 和 Linux；下面分别列出安装命令，其余示例以 Windows PowerShell 为主。

01 / 安装与检查

需要 Python 3.10 或更新版本。下载仓库后，在仓库根目录运行对应系统的安装脚本。

Linux / Bash

git clone https://github.com/lxy12306/gd.git
cd gd
bash linux/setup.sh
.venv/bin/gd --version
.venv/bin/gd list

Linux 入口默认安装在 ~/.local/bin/gd。确保 ~/.local/bin 位于 PATH；也可直接运行 .venv/bin/gd。开发环境用 bash linux/setup.sh --dev，只安装核心用 --core-only，只准备环境用 --no-launcher。移除全局入口可运行 .venv/bin/python linux/install-gd.py --uninstall。

Windows / PowerShell

git clone https://github.com/lxy12306/gd.git
cd gd
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\setup.ps1
gd --version
gd list

安装脚本准备项目虚拟环境和全局 gd 命令。以后可从任意目录运行 gd；Windows 开发环境在安装命令末尾加 -Dev。

示例中的路径、站点地址和对象名需要按你的环境替换。配置文件和写入密钥只保存在本机，不应提交到仓库。

02 / 管理本地脚本

注册一次后，脚本可按名称调用。注册只记录脚本路径，不会复制或执行脚本。

gd add hello .\examples\hello.py -d "问候示例"
gd hello --name 张三
gd run hello -- --name 张三
gd info hello
gd list
gd remove hello

支持 Python、PowerShell、Bash 和可执行文件。默认沿用当前工作目录；需要固定工作目录时给 gd add 加 --cwd。注册文件默认在 ~/.gd/scripts.json，移除注册不会删除脚本文件。

03 / 操作 OSS 文件

OSS 模块负责列举、上传、下载、检索和查看对象。首次使用先按仓库的 OSS 文档配置 ~/.ossenv。

gd oss config
gd oss ls
gd oss put .\image.png images/
gd oss get images/image.png .\image.png
gd oss search 文生图
gd oss stat images/image.png

上传同名对象默认不会覆盖；确需覆盖时加 --overwrite。在 Windows 上，如果本机的 APNetwork 路径影响 OSS 连接，可给当前命令加 --direct-wlan，让这次 OSS 请求从 WLAN 直连。

gd oss --direct-wlan stat images/image.png

04 / 发布静态站点

gd site 可发布 HTML、CSS、JavaScript 和图片。目标须提供 GD 兼容的写入接口；只知道一个普通网页网址无法上传。

发布到已配置的站点

gd site list
gd site publish .\docs --site chatgpt

发布时会逐个上传文件，再从公开地址回读 SHA-256 响应头核对。这个站点的首页源文件是 docs/index.html，说明页是 docs/guide.html。

配置新的 ChatGPT Site

gd site add mysite --provider chatgpt --url https://your-site.chatgpt.site
gd site login mysite
gd site publish .\dist --site mysite

目标站点需要先部署 GD 发布器及其存储和写入密钥。站点地址与密钥保存在本机 ~/.gd/sites.json；gd site list 不输出密钥。

配置自有服务器

gd site add myserver --provider self --url https://example.com --root D:\sites\public
gd site login myserver
gd site serve --site myserver --host 127.0.0.1 --port 8765

公网访问需要自备 DNS、HTTPS 和反向代理。另开终端执行 gd site publish .\dist --site myserver。单文件最大 20 MB；目录发布跳过隐藏文件，并拒绝符号链接。
